# VK Video Tweaks

Tampermonkey userscript для управления громкостью аудио на VK Video.

## Возможности

- 🎚️ **Усиление громкости** — увеличьте громкость видео до 10x
- 🎯 **Точный выбор** — работайте с конкретным video-элементом на странице
- 🎨 **Удобный интерфейс** — минималистичный popup с drag-and-drop
- ⚡ **Быстрый доступ** — активация одним движением мыши в угол экрана

## Функции

### 🎵 Audio Gain

- Регулировка громкости от 0 до 10
- Значение по умолчанию: **4**
- Работает через Web Audio API

### 📺 Toggle Recommendations

- Кнопка для скрытия/показа блока рекомендаций "Watch also"
- Скрывает всю колонку, чтобы контент расширялся на освободившееся место

## Использование

1. Откройте любое видео на [vkvideo.ru](https://vkvideo.ru)
2. Наведите курсор на **синий квадрат** в левом верхнем углу экрана
3. Появится popup с настройками:

| Поле                          | Описание                                |
| ----------------------------- | --------------------------------------- |
| **Video Element**             | Выбор видео (обновляется автоматически) |
| **Gain Value**                | Значение усиления (0-10)                |
| **Apply Audio Gain**          | Применить выбранное значение            |
| **Hide/Show Recommendations** | Скрыть/показать рекомендации            |

## Дополнительно

- **Drag & Drop** — перетаскивайте popup за заголовок
- **Автоскрытие** — popup скрывается через 3 секунды после ухода курсора
- **Shadow DOM** — автоматически находит видео внутри `vk-video-player`

## Настройки

| Параметр         | По умолчанию | Описание                                         |
| ---------------- | ------------ | ------------------------------------------------ |
| **Gain Value**   | `4`          | Значение усиления громкости (0-10)               |
| **Hide Timeout** | `3 сек`      | Время до скрытия popup после ухода курсора       |
| **Trigger Zone** | `40×40 px`   | Область в левом верхнем углу для активации popup |
